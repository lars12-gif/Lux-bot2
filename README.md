# 👑 Lux Bot — منصة لوكس

منصة عربية لإدارة بوتات واتساب، بواجهة سوداء وذهبية، وموقع Streamlit منفصل عن محرك Node.js.

> هذا الإصدار مبني على مشروع Reze-Ai الأصلي. راجع `LICENSE` و`README_ORIGINAL.md` للاطلاع على إشعارات المصدر والمساهمين. لا تحذف إشعار الرخصة الأصلية عند إعادة التوزيع.

## المكونات

- `index.js`: محرك MeowSab/Baileys الأصلي بعد إضافة إعدادات خاصة بكل مستخدم.
- `platform/server.js`: واجهة API للحسابات، جلسات التشغيل، ورموز الاقتران.
- `website/app.py`: لوحة Streamlit عربية باتجاه RTL.
- `system/command-gate.js`: بوابة تعطيل الإضافات حسب حساب المستخدم.
- `platform/commands-catalog.json`: قائمة الإضافات المعروضة في لوحة التحكم.

## متطلبات التشغيل

- Node.js 20 أو أحدث.
- Python 3.10 أو أحدث.
- استضافة تسمح بعمليات Node.js المستمرة والاتصالات الصادرة.
- تخزين دائم لمجلد `platform-data`.

## 1) تثبيت محرك المنصة

```bash
npm install
cp .env.example .env
```

ضع قيمة عشوائية طويلة في `JWT_SECRET`، وحدد `WEBSITE_ORIGIN` بعنوان موقع Streamlit بعد نشره.

## 2) تشغيل واجهة API

```bash
npm run platform
```

سيعمل الخادم على المنفذ المحدد في `PORT` (الافتراضي 8080).

## 3) تشغيل موقع Streamlit

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export LUX_API_URL="https://عنوان-api-الخاص-بك"
streamlit run website/app.py --server.port 8501
```

في Windows استخدم تفعيل البيئة الافتراضية المناسب لنظامك.

## 4) ربط واتساب

1. أنشئ حساباً في موقع Lux Bot.
2. افتح صفحة «ربط واتساب».
3. أدخل رقمك بصيغة دولية مع مفتاح الدولة.
4. اضغط «إنشاء رمز الاقتران».
5. افتح واتساب في هاتفك: الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف.
6. أدخل الرمز الذي يظهر في الموقع.

لا تطلب رمز شخص آخر ولا تشاركه. يجب أن يربط كل مستخدم رقمه بنفسه.

## 5) إدارة الأوامر

تعطيل الإضافة يحفظ حالتها في ملف مستقل داخل مجلد حساب المستخدم، ويُقرأ عند تنفيذ الإضافة. قد تحتاج بعض الإضافات التي تعمل كأحداث تلقائية إلى اختبار خاص على نسخة MeowSab المستعملة.

## ملاحظات تشغيل مهمة

- كل مستخدم يحصل على مجلد جلسة وقاعدة بيانات منفصلين.
- لا ترفع `.env` أو `platform-data/` أو ملفات الجلسات إلى GitHub.
- استخدم HTTPS للموقع وواجهة API.
- خذ نسخاً احتياطية مشفرة، ولا تعرض سجلات الجلسات أو رموز الاقتران للمستخدمين الآخرين.
- يضع الخادم حداً افتراضياً قدره 10 عمليات بوت متزامنة؛ عدّله وفق قدرة الاستضافة.
- لوحة Streamlit وواجهة API يجب نشرهما كخدمتين منفصلتين، بينما يجب أن يبقى محرك Node.js على استضافة تدعم العمليات المستمرة.

## قيود هذا الإصدار

هذا أرشيف تأسيسي معدل وليس شهادة بأن جميع وظائف واتساب اختُبرت على استضافتك. يعتمد إصدار MeowSab الموجود في `package.json` على واجهة تسجيل الدخول `login.method = "pair"` وحقلي `number` و`code` كما في المصدر الأصلي؛ يجب اختبار إصدار المكتبة على استضافة فعلية للتأكد من أن الرمز المخصص يظهر ويُقبل بالطريقة المتوقعة. كذلك يجب اختبار إعادة الاتصال بعد إعادة تشغيل الخادم، وإدارة العمليات المتعددة، وكل إضافة على حدة قبل فتح التسجيل للعامة.

تم تعطيل إضافتي تنفيذ أوامر النظام وJavaScript (`owners/exec.js` و`owners/eval.js`) لأن إتاحتهما لمستخدمي منصة عامة قد تمنح كل مستخدم إمكانية تنفيذ تعليمات على خادم الاستضافة.

## الحقوق

- يحتفظ المشروع الأصلي بإشعاراته ورخصته كما تقتضي شروطها.
- إضافات Lux Bot ولوحة التحكم الجديدة يمكن نسبها إلى مطورها الجديد بحسب مساهمته الفعلية.
- لا تنسب الشيفرة الأصلية بالكامل إلى نفسك.
