# ملاحظات الأمان

- تم تعطيل إضافتي `owners/eval.js` و`owners/exec.js` لأنهما تسمحان بتنفيذ JavaScript أو أوامر نظام على الخادم.
- لا تعرض مجلدات الجلسات أو ملفات قاعدة البيانات أو `.env` عبر خادم الويب.
- استخدم HTTPS، وسراً قوياً لـ JWT، وحدوداً لمحاولات الدخول.
- لا تسمح للمستخدم باختيار مسار ملف أو اسم عملية نظام.
- راجع الإضافات التي تستخدم `child_process` أو تجلب ملفات من روابط خارجية قبل فتح المنصة للعامة.
- رمز الاقتران وجلسة واتساب بيانات حساسة؛ لا تسجلها في السجلات ولا تعرضها إلا لصاحب الحساب.
